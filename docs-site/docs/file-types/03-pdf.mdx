A `.pdf` opens in the browser's built-in PDF viewer, so search, zoom and page thumbnails work the way the reader is used to. The viewer loads the file in byte ranges, so a long document starts showing before it has finished downloading.

```bash
jalco-drop report.pdf
jalco-drop -p hunter2 -e 7d contract.pdf
```

**Download** in the `...` menu saves the original file.
