| Upload | Opens as |
| --- | --- |
| [Markdown](/file-types/markdown) | A rendered document with GitHub-flavoured tables and task lists, frontmatter as properties, and embedded video |
| [HTML](/file-types/html) | The page, running in a sandboxed frame |
| [PDF](/file-types/pdf) | The browser's PDF viewer |
| [Code and text](/file-types/code) | Highlighted in your [code theme](/settings), with line links like `#L12`. Terminal output keeps its colours |
| [JSON and JSON Lines](/file-types/json) | A tree you can fold, or a table with one row per line |
| [CSV and TSV](/file-types/csv) | A table with sticky headers |
| [Diffs and patches](/file-types/diffs) | Every changed file with its status, `+`/`−` counts, and old and new line numbers |
| [Test reports](/file-types/test-reports) | JUnit XML and Playwright JSON, failures first |
| [Images](/file-types/images) | A centred preview |
| [SVG](/file-types/svg) | An image, rendered in a sandbox |
| [Video and audio](/file-types/video-and-audio) | A player that seeks by byte range |
| [Excalidraw and tldraw](/file-types/drawings) | The drawing itself |
| [Scrawl captures](/file-types/scrawl) | The recording beside its transcript and marked moments |
| [Superwhisper recordings](/file-types/superwhisper) | Audio on top, each line a timestamp that seeks it, speakers named |
| [Claude Code, Codex and Pi sessions](/file-types/agent-sessions) | The conversation: prompts, replies and one line per tool call |
| [Folders and zips](/file-types/folders) | A share page with a file tree and a preview drawer |
| Anything else | A download page |

Every rendered format has a **Source** view at `?view=source`. Every drop's raw bytes are at `/<slug>/<filename>`, with `?download=1` to force a download. Raw HTML and SVG are always served as plain text or in a sandbox, so a drop can never run script on your domain. Text files over 512 KB open as a download page.

Files inside a folder open in the same formats, in the share page's drawer.

The `...` button in the top-right holds every action for a file. Right-click anywhere for the same actions as a pie menu.

Every format lives in `src/formats/`, so you can [add your own](/file-types/custom).
