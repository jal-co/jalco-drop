## How it works

**It opens like you made it.** Code is highlighted, markdown renders, CSV becomes a table, video and PDFs play in the page. A folder opens as a "sent you" page with a file tree, and a [Scrawl](https://scrawl.kitlangton.com) capture opens with its transcript beside the video.

**The link is the permission.** Anyone who has it can open it, so the address is 10 random characters. Add a password and the server keeps the bytes back until it's entered. Add an expiry and the drop is deleted for you.

**Bots get their own name.** A CI job or a chat bot uploads with its own token. Its drops say who sent them and carry its icon, and revoking the token stops it at once.

**Agents can read what they're sent.** Add `?format=json` to any link to get its files, raw URLs, transcript and marked moments. Pages advertise it, so an agent that fetches the link finds it.

**It's yours.** Your domain, your storage, your name on every share page. One Worker and an R2 bucket on Cloudflare, or one container with a disk or any S3 bucket.

## For agents

```bash
npx skills add jal-co/jalco-drop
```

With the skill, an agent uploads with the right password and expiry, hands back the link, and reads any drop link you paste to it.
